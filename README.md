# Kinopub Helper

Расширение Chrome (MV3), призванное улучшить взаимодействие с сервисом **Kinopub**.

## Функционал

1.  Переключение серий через медиа кнопки устройства (есть на многих клавиатурах)
   - Переключение на **следующую серию** по медиакнопке **Next Track**.
   - Переключение на **предыдущую серию** по медиакнопке **Previous Track**.
   - Срабатывание **только для сериалов**.

---

## Настройки

1. Открой настройки расширения:
    - `chrome://extensions` → Kinopub Helper → **Сведения** → **Параметры расширений**
    - либо найти иконку в списке расширений в верхнем тулбаре и при нажатии там появится кнопка для перехода в настройки
2. В поле **Хост KinoPub** укажи домен кинопаба (персонального зеркала или иной ссылки на него), например: `example-mirror.com`
3. Нажми **Сохранить**
4. Нажми **Выдать доступ к хосту** и подтверди разрешение

По умолчанию стоит `kino.pub`.

---

## Как пользоваться

- Во время просмотра **сериала**:
    - **Next Track** → следующая серия
    - **Previous Track** → предыдущая серия

Расширение не реагирует:
- если это фильм (например `.../s0e1`)
- если хост не совпадает с настройками / не выданы права

---

## Установка зависимостей

```bash
npm i
```

## Сборка

```bash
npm run build
```

После сборки появится:
- `dist/` — готовая папка расширения для загрузки
- `kinopub-helper-<version>.zip` — архив релиза

# Тестирование без реального Kinopub

В проекте есть минимальный имитатор вкладки “Kinopub сериал” + мини‑сервер на Express:
`tests/series-switcher/`

## 1) Запуск тестового стенда

```bash
cd tests/series-switcher
npm i
npm run start
```

Сервер поднимется на:
- `http://localhost:5177`

## 2) Открыть тестовую страницу

Открой в браузере (пример сериала):
- `http://localhost:5177/item/view/18009/s1e1`

Пример “фильма” (season=0, расширение не должно переключать):
- `http://localhost:5177/item/view/978/s0e1`

На странице:
- есть `<video>` (без внешних файлов — поток генерится canvas’ом)
- кнопки `.btn-next` и `.btn-prev`
- перемотка по плейлисту и обновление URL

## 3) Разрешить хост localhost для расширения

1. Открой настройки расширения (см. выше)
2. Host: `localhost:5177`
3. **Save**
4. **Grant host permission**
5. Перезагрузи вкладку тестовой страницы (F5)

## 4) Проверка

1. Убедись, что видео реально играет (идёт анимация/время).
2. Нажми медиа‑кнопки:
    - Next Track → должен перейти на `/s1e2`, `/s1e3`, ...
    - Previous Track → должен вернуться назад
3. Перейди на URL фильма `/s0e1` и проверь, что кнопки не переключают.

## Troubleshooting

- Если медиа‑кнопки не попадают в Chrome: убедись, что **Chrome** — активная медиа‑сессия
  (то есть видео реально играет в Chrome).
- Если не работает на зеркале: проверь, что хост сохранён и выданы разрешения.
